# MGF正常レコード回収の実装・検証（2026-10-21）

対象はLEP-i native momentバッチ。2022年の全再実行は行っていない。
外部通信・ダウンロード・本番出力／検証receiptの更新は行わず、実データ試験は既存のローカルCDFだけを使用した。

## 実装

- 整数TT2000で補間端点を選び、整数の時間差から線形補間係数を計算。公開関数には有効な粒子時刻上の有限磁場を渡す。
- 同一時刻の磁場値またはqualityが矛盾する場合は、その点への一致と、その点を端点とする補間だけを無効化。ファイル間重複も同じ規則。
- 公称MGF時間範囲±32秒を外れるレコード（NaT含む）は索引で隔離。途中の隔離箇所をまたぐ補間は許可しない。残った時刻列の逆転は検証失敗。
- CDF構造、長さ、埋込チェックサム、必須変数のレコード対応、全必須レコード読み出しの検証は維持。LEP-i検証条件、エネルギー範囲、最大MGFギャップなどは維持。
- 全時刻有効はcomplete、一部はpartial、全時刻無効と判定できた場合はexcluded。変数不足・破損・判定不能はfailed_validation、計算例外・timeoutは従来どおり失敗。
- 新規理由ビット: 16 conflicting_mgf_epoch、32 quarantined_mgf_interval。元粒子時刻・counts・qualityと出典を保持し、無効momentをNaNにする。
- 検証receiptに入力全体の隔離索引・矛盾レコード対、NPZ/manifestに使用レコード索引・区間・曖昧点・粒子時刻上の磁場を保存。
- 処理方針とソースハッシュの変更により別プロファイルとなる。旧プロファイルからのcomplete自動再利用は今回の互換対象外。本番の既存ファイルは変更していない。

## 合成データと回帰検証

- バッチunit/integration tests: 46件。
- GSM変換tests: 15件。
- 128 ns離れた2点がUnix floatで同じ値になる例と、間の64 ns点での既知の補間値を検証。
- 正常な時間変動磁場では、公開関数へ元MGFグリッドを直接渡す参照処理と、新処理の48 moment系列を比較（rtol/atol各1e-13）。
- 矛盾磁場、矛盾quality、ファイル間矛盾、範囲外接頭レコード、途中の隔離、全矛盾・全範囲外・全非有限・全ゼロ、変数不足・時刻逆転を検証。
- 正常部分の全48系列、元粒子時刻、counts/quality、無効行のNaN、単一有効時刻を検証。CDFの変更がないことも合成fixtureのSHA256で確認。
- classification_version=2のexcludedも同一入力でresumeできることを確認。
- check_partial_worker.py、check_worker_edges.pyも実行。
